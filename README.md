# Chanindhu Bandara - AI Engineer Portfolio

Static portfolio website for Chanindhu Bandara, built with HTML, CSS, and JavaScript and published with GitHub Pages. The site is designed to point reviewers toward the strongest engineering work first, with EduGuard positioned as the flagship AI/full-stack project.

Live site: [https://chanindhu.github.io/](https://chanindhu.github.io/)

## What This Portfolio Shows

- Flagship positioning for EduGuard as the main AI academic integrity platform.
- Selected project coverage across AI/ML, full-stack engineering, AWS cloud deployment, distributed systems, Android, Java, C#, and C systems programming.
- Direct links back to GitHub repositories so reviewers can inspect source code, screenshots, documentation, and proof artifacts.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

Push the contents of this repository to the `main` branch and enable GitHub Pages for the root of the branch.
