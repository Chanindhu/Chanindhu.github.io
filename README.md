# Chanindhu Bandara — AI Engineer Portfolio

Static portfolio website built with HTML, CSS, and JavaScript. It is ready for GitHub Pages.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

Upload the contents of this folder to the root of the `Chanindhu.github.io` repository and enable GitHub Pages from the `main` branch.
